# Hi, I'm Brad 👋

Curious by nature — I like figuring out how things work, tinkering until
they work better, and generally leaving whatever I touch a little improved.

**By day:** Quality Rep & H&S Advisor in industrial supply, working on
nuclear-sector quality compliance (CSA N299.4), ISO 9001 audit readiness,
and ISO 45001 certification.


## 🌌 Featured project

**[The Firmament](https://github.com/bferd/the-firmament)** — a self-hosted
dashboard for my homelab. Node.js/Docker app with live Proxmox and backup
metrics, SSO via Authelia, and 15 selectable themes, all running behind a
hardened reverse-proxy setup.

**[Nooksplore](https://nooksplore.com)** — an AI-powered local travel guide
app. PHP/SQLite backend with a multi-agent AI pipeline for destination
search, full auth and Stripe-based subscriptions, and a security-hardened
deployment (A rating on securityheaders.com).
